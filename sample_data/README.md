# Sample data

`authorised_demo_captures/` holds **CONTROLLED SYNTHETIC DEMONSTRATION DATA — NOT REAL CUSTOMER TRAFFIC.**

Every PCAP is generated by `backend/tests/fixtures/generate.py` with fixed timestamps and a fixed throw-away certificate
(no real hosts, users or mail). `manifest.json` records each file's scenario and the rules it is expected to trigger.
Regenerate with `cd backend && .venv/bin/python -m tests.fixtures.generate ../sample_data/authorised_demo_captures`.

The UI's "Load demo dataset" button loads four of these (flagged `is_demo`) and can remove them again.
`corrupted`, `empty` and `unsupported_linktype` are deliberately invalid and exist to test error handling.
